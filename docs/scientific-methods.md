# 前瞻七因子、交易參考與背景警報

## 橫截面校準

主分數仍採固定基準權重：動量10%、估值15%、品質20%、增長20%、
波動10%、持倉與分析師共識15%、均線結構10%。
輸入保持原有七因子的定義；不以當前基本面回填歷史。

每個原始細項先轉成「愈高愈優」的數值。
估值倍數、負債股權比、波動、ATR%、空頭比例和分析師評級反號；
非正估值倍數視為無效。非單調偏好採負絕對距離：
RSI距60、Beta距0.65、股息殖利率距5%、機構持股距85%、
內部人持股距30%；其餘原始細項保持正向。
這些仍是待驗證的研究假設。

有N個有效成分股時，p=(平均同分名次−0.5)/N。
同一細項板塊有效樣本至少5個，則p=0.7*p_sector+0.3*p_universe；
不足則只用全池；全池不足20個則細項無數據。分數=10*p−5。
板塊來自當輪S&P成分表的GICS分類。分位只涵蓋實際成功取得的資料，
免費來源限流／缺失可能影響排名。
非成分股收藏不改動參照分布；以S&P樣本的中點經驗CDF評估，
板塊若可用則依Yahoo板塊對應（非官方GICS原始分類）比較。

組內只平均有效細項；整組缺失剔除並重新正規化固定權重。
有效細項不足50%或不足4組則總分為「數據不足」，不發HOLD。
總分貢獻=組分數*有效權重。完整度不是預測信心。

## 只由現在開始的效能紀錄

research_runs/research_scores由資料庫實際寫入時間產生時間戳。
不讀取舊回測作為新制紀錄，不回填歷史分數，也不複製開發測試紀錄至正式環境。
每輪掃描保存每股分數；個股計算另存一筆，不覆蓋全池最近掃描。
原始細項、校準後組分數、固定權重與IC權重／總分隨快照保存。

入場基準為評分快照之後第一個已完成交易時段的adjusted close，
不是快照之前已知的收盤，也不是盤中未完成日線。
出場取美東入場日期加7、28、84天之後第一個完整收盤，最多延後7天。
價格觀察使用XNYS日曆的實際收盤時刻（含提早收市），只有來源日期已完成才入庫。
adjusted價格可由Yahoo修訂；沒有可用結算價的下市股票會缺失，不當成零回報。

每股每個美東觀察日先只採首筆有效快照，再按入場日去重；
每個週期使用不重疊入場日期群組。
每期每因子至少30股，至少12個有效不重疊群組才檢定。
Rank IC為同一期組分數與未來回報的Spearman平均同分等級相關；
高減低回報差為>=80%分位和<=20%分位的等權回報差，同分可擴大組別。
各期IC與spread再等權平均。
以4999次日期群組bootstrap取95%均值區間，使用中心化bootstrap雙尾p值，
同一週期的七因子做BH多重檢定。q<=.05且區間下限>0才採正向IC。
樣本不足顯示「尚未驗證」；未排除零顯示「效能未證實」。
負向顯著IC會披露但不自動反向交易。

另列IC加權分：只用當時計算已到期的1週驗證結果，
至少3個正向顯著且本股有資料的因子，以正的平均IC正規化加權。
權重與該股IC加權分在計算時凍結，不在日後用新證據改寫舊快照。
它不取代固定權重分，也不代表經外樣本證明的交易策略。
交易成本、下市缺價、存活偏差與多次嘗試策略的風險仍存在。

## 交易參考

Wilder ATR(14)：TR=max(H−L,|H−前收|,|L−前收|)；
首14個有效TR均值作種子，後續ATR=(13*舊ATR+TR)/14。
入場計算價為最新adjusted日線收盤，止損=入場−2*ATR；
若止損不為正或輸入不足則不可計算。
入場區間=[20根最低低點,min(目前收盤,低點+0.5*ATR)]。
預設參考資金US$100,000、每筆風險1%，可調：
股數=min(floor(資金*風險比例/(入場−止損)),floor(資金/入場))。
每個股票獨立估算，未加槓桿；沒有組合風險／相關性配置。
20日成交額為最近20個完整交易日Close*Volume的均值，
不足US$10M標示低流動性。價差=(ask−bid)/中間價，無有效來源則「無法取得」。
價格均為分析口徑，不保證成交；未計跳空、滑價、手續費，非投資建議。

## 背景執行與部署

`python run_dashboard.py`在任何頁面／Streamlit session建立前啟動獨立worker程序。
worker以PostgreSQL advisory lock防止多實例同時掃描，並以全域最近成功時間控制
每小時一次，與開頁／關頁無關。它先更新SPY情緒，再掃描全S&P池及額外收藏、
保存評分／來源時間／警報／背景完成時間；來源失敗不捏造中性值。
綜合情緒不可用時保持「無數據」，或保留有明確原時間的上次成功值；
VIX反向百分位是另一個指標，絕不偽裝為StockTwits／新聞綜合情緒。

警報包括：固定權重校準分變動達門檻（預設1分）、21個共同交易日對SPY回報差
穿越零、綜合情緒或獨立VIX反向指標變動達門檻（預設20/100），以及業績7天內。
同一業績日期的提醒以唯一鍵去重；其他事件按新觀察時間記錄。
警報設定／背景收藏為共用，介面有標明；不取代既有收藏／通知功能。
研究警報沒有接駁站外推送，不聲稱已發出通知。

開發資料表來源：schema/scientific_research.sql，已獨立套用開發庫。
程式啟動不建表、不跑migration；Replit管理的正式結構由Publish套用。
正式驗證應由正式站首次真實執行起算，勿選擇複製開發紀錄。
Autoscale閒置會休眠，沒有24/7背景執行保證；
需使用者批准Reserved VM並重新發布，或另行設定Scheduled Deployment
執行`python -m research_worker --once`。此工作沒有自行發布或自動改成收費VM。
